# Промт для продолжения работы над GooseDeluxe

Скопируй всё ниже в новый чат (Claude Code или Claude с доступом к репозиторию) целиком.

---

Ты продолжаешь работу над **GooseDeluxe**: это мод для Desktop Goose 0.31 (гусь, который бегает по рабочему столу Windows). Весь код лежит в репозитории GitHub **Join99-gtm/MAUN**, в ветке **`claude/great-maxwell-epaumj`**. Работу продолжай в этой ветке. Pull request создавай, только если тебя попросят. Всё прочитай, прежде чем что-то менять.

## Как общаться с пользователем

- Пиши **только по-русски**, и всё видимое пользователю в моде тоже должно быть на русском. Он прямо просил: «делай всё на русском».
- Пользователь не программист. Его раздражают длинные многошаговые инструкции («сделай всё сам»). Давай 1–3 шага, а лучше делай так, чтобы шагов не было совсем. Готовую сборку отправляй **одним zip-архивом с установщиком** и отдельной карточкой файла. Однажды он не заметил zip среди картинок и спросил «Где zip?».
- Он присылает скриншоты. Смотри на них внимательно: скриншоты много раз давали разгадку (например, английская записка «Not-epad» показала, что мод не загружен).
- Облачные кредиты ограничены. Не трать их на лишнее и сохраняй результат (коммит и пуш) после каждого законченного куска.

## Как устроен мод (главное)

- Мод — `GooseDeluxe/` (C#, .NET Framework 4.5.2, WinForms, GDI+), собирается в `GooseDeluxe.dll`. Ставится в `<гусь>\Assets\Mods\GooseDeluxe\` вместе с `GooseDeluxe.ini`. В `config.ini` гуся нужен `EnableMods=True`. При каждом запуске гусь спрашивает «Mod Enabler Warning» (это окно автора гуся, по-английски), ответить нужно «Да».
- Как гусь грузит моды (`ModSupport.LoadMods`): `Assembly.UnsafeLoadFrom` для каждой .dll в каждой папке `Assets/Mods/*`. Ищет типы `IMod` и `GooseTaskInfo`. Если `GetTypes` падает, показывает окно «Couldn't Load Mod». Отметка «из интернета» (MOTW) загрузке не мешает. Если `Init()` мода бросит исключение, упадёт весь гусь. До ответа на «Mod Enabler Warning» главное окно гуся скрыто.
- `ModEntryPoint` → `Controller.Init`: пишет лог и `GooseDeluxe.status`, ставит русские записки (`RussianPack`) и русские мемы (`MemeTranslator.Apply`). Всё остальное подключается на первом `PreTick` (`Controller.Hook`): своё окно-оверлей с попиксельной прозрачностью (`OverlayWindow`, `UpdateLayeredWindow`), фиксированный шаг 120 Гц (`Fixes/FixedTimestep`), честная колода проделок (`Fixes/DeckFixer`, у гуся там алгоритм Саттоло), заморозка движка (`Fixes/Engine`), полноэкранные игры (`Fixes/FullscreenDetector`), трей (`UI/Tray`), горячие клавиши Ctrl+Alt+G/H/P/M (`RegisterHotKey` плюс запасной опрос `Fixes/HotkeyPoller`), гости и гусиная почта через ntfy.sh (`Net/`, `Tasks/`, `Guests.cs`), времена года (`Seasons/`).
- `GooseDeluxe.status` — одна строка `started|hooked|failed | время UTC | версия | подробности`. По ней установщик понимает, что мод работает.
- Своё окно ловит клики только там, где курсор над гусем или над кучей листьев (снимается `WS_EX_TRANSPARENT`). Правый клик открывает меню, левый — гудок, клик по куче «пинает» её (`AutumnControl.KickAt` → `LeafPile.Kick` осеннего мода). Кучи рисует окно гуся под нашим, поэтому над каждой кучей в нашем окне лежит заливка с альфой 1/255: без неё окно пропускает клик.
- Мемы и записки без повторов (`UI/GooseForms` + `NoRepeatDeck`). Гусь создаёт окно мема или блокнота в начале задачи, а показывает его позже из другого потока. Мы до показа подменяем картинку или текст на следующий по колоде и переименовываем «Goose "Not-epad"» в «Гусиный «Блокнот»».
- Мемы по-русски (`MemeTranslator`). Для 6 мемов гуся (Meme1, 2, 3, 5, 6, 7) заданы области с английским текстом. Буквы стираются заливкой из окружения (по вертикали для забора, «по кольцам» для остальных), русский текст вписывается подобранным шрифтом. Русские копии заменяют файлы в `Assets\Images\Memes`, оригиналы лежат в `Memes\en`: гусь не смотрит в подпапки и берёт из корня **любой файл**, поэтому класть туда не-картинки нельзя. Meme4 и GooseDance.gif без текста.
- Пульт (`UI/ControlPanel`), три вкладки: «Пульт», «Настройки», «Проверка» (самопроверка всех частей и «Скопировать отчёт»). Открывается правым кликом по гусю, кликом по значку у часов или Ctrl+Alt+M. Все настройки — в `DeluxeConfig` / `GooseDeluxe.ini`. Новые ключи сами дописываются в старый ini.
- Установщик: `installer/install.ps1` (UTF-8 **с BOM** — обязательно для PowerShell 5.1) и `installer/Установить GooseDeluxe.bat` (только ASCII и **CRLF**, русские окна через `-EncodedCommand`). Коды выхода: 0 — успех, 2 — мод не отозвался, 3 — ошибка, уже показанная пользователю. `.bat` показывает своё окно только при коде 1 (PowerShell не смог запустить скрипт). Установщик ищет гуся так: сначала запущенный процесс, затем ярлыки (рабочий стол, «Пуск», панель задач), затем Рабочий стол, Загрузки, Документы и профиль, в последнюю очередь по дискам. Если гуся нет, распаковывает .rar друга. Мод ставится во **все** копии; дальше установщик закрывает гуся, запускает его и до 150 с ждёт статус. По заголовку окна процесса он видит «Mod Enabler Warning» и «Couldn't Load Mod». Причину неудачи он объясняет по-русски и копирует отчёт в буфер.

## История версий (кратко)

- 0.1 — графика и анимации гуся.
- 0.2 — починки (скорость, честный рандом, игры на весь экран), трей, горячие клавиши, русский пакет, «Гусь к другу» (почта через ntfy).
- 0.3 — времена года: листья только осенью, зимой снег, сугробы, шарф, новогодняя шапка.
- 0.4 — пульт, меню по правому клику, самопроверка.
- 0.5 — установщик с проверкой запуска, клик по кучам листьев, мемы без повторов, русский блокнот, левый клик = гудок.
- 0.6 — надписи на мемах по-русски.
- 0.6.1 — мемы переводятся в фоне (не задерживают старт гуся); установщик выясняет, почему гусь закрылся.
- 0.6.2 — ESC держать 1,5 с вместо ~8 (`EscHoldSeconds`), русская полоска «Держи ESC — гусь уходит…»; счётчик самого гуся (`EscToQuitOverlay.curQuitAlpha`) мод держит на нуле.
- 0.6.3 — (текущая) **пульт наконец кликается на Windows**. Цикл гуся `Program.HandleApplicationIdle` каждые ~8 мс
  делает `mainForm.TopMost = true`, а WinForms при этом вызывает SetWindowPos без SWP_NOACTIVATE. В итоге окно гуся
  активировалось, а наши окна в том же потоке (пульт, меню, диалоги, записки) теряли фокус: клики пропадали, список
  шляп закрывался. `Fixes/Engine` подменяет этот цикл таким же, но без активации. Под Wine проблема не проявлялась.
  Ещё в 0.6.3: кнопка «Убрать листья» (пульт и меню), настройка `LeafPiles`, ESC по умолчанию 3 с (попросил
  пользователь), кнопка «Папка мемов». Добавлен запасной путь для клика по куче: мод опрашивает левую кнопку через
  `GetAsyncKeyState`, если окно-оверлей клик не поймало (у пользователя на Windows клик по куче не срабатывал).

## Сборка и проверка (Linux, облачная сессия)

```
export DOTNET_ROLL_FORWARD=Major PATH="$PATH:/root/.dotnet/tools"
dotnet build GooseDeluxe -c Release
dotnet run --project tools/Tests -c Release -- tools/mock_ntfy.py "<папка гуся>"      # 187 проверок, должно быть ALL PASSED
(cd tools/UiPreview && dotnet build -c Release && xvfb-run -a mono bin/Release/net452/UiPreview.exe clicks)   # CLICK TEST PASSED
dotnet run --project tools/Tests -c Release -- --write-default-ini GooseDeluxe/GooseDeluxe.ini
SP=/tmp/goose-work bash tools/installer-tests/scenarios.sh          # установщик, pwsh 7, -NoLaunch
SP=/tmp/goose-work bash tools/installer-tests/launch-scenarios.sh   # установщик с «гусём-подделкой»
```

- Для тестов нужен сам гусь. Попроси у пользователя `Desktop_Goose_v0.31.rar` и распакуй `bsdtar -xf` в `$SP/goose/`, чтобы получилось `$SP/goose/Desktop Goose v0.31/DesktopGoose v0.31/`. Из него же взят `lib/GooseModdingAPI.dll`.
- Нужные инструменты: .NET SDK (+ `DOTNET_ROLL_FORWARD=Major`), mono, xvfb, ImageMagick; для установщика — pwsh (`dotnet tool install -g powershell`); для анализа снимков — python3, pillow, numpy.
- **Настоящий гусь под Wine** (так проверена 0.5–0.6):
  1. `dpkg --add-architecture i386`, затем `apt-get install wine wine32:i386 xdotool xcompmgr`. Если мешает `libgd3:i386`, сначала поставь его отдельно.
  2. Wine Mono 8.1.0 скачай с GitHub (`wine-mono-8.1.0-x86.tar.xz`, dl.winehq.org закрыт прокси) и распакуй в `/usr/share/wine/mono/`.
  3. `locale-gen ru_RU.UTF-8`.
  4. `WINEARCH=win32 WINEPREFIX=$SP/wp wineboot -i`.
  5. Положи гуся в `$SP/wp/drive_c/users/root/Desktop/Гусь` и поставь `EnableMods=True`.
  6. Запуск: `tools/wine/wine_start.sh`. Он поднимает Xvfb :77 с xcompmgr (без композитора альфа 1/255 рисуется чёрным), жмёт «Да» и ждёт статус. Помощники: `leaves.py` (найти кучи на снимке), `findgoose.py`, `textbox.py`.
  7. Команды гусю можно слать через `tools/mock_ntfy.py`: `NtfyServer=http://127.0.0.1:порт` в ini, POST «мем» или «записка» в топик `goosedeluxe-<код в нижнем регистре без дефисов>`.
- Ограничения Wine: Ctrl+Alt+M не срабатывает (Wine не перехватывает глобальные клавиши без фокуса), PowerShell 7 для Windows под Wine 9 падает. Поэтому окна установщика на настоящей Windows пока не проверены.

## Что делать дальше (по порядку)

1. **Узнать результат установки у пользователя** и разобрать отчёт, если он пришлёт. Если мод снова не загрузился, отчёт покажет, что в папке мода, что в логе, какой антивирус, какие окна видел установщик и откуда был запущен гусь.
2. **Больше русских мемов.** У гуся всего 8 мемов. Пользователь хочет больше, и с гусём на русском. Чужие мемы из интернета в мод не вшивай: у них есть авторы. Нарисуй **свои оригинальные мемы** нашим рисовальщиком гуся (`GooseRenderer`, превью через `tools/Preview`, libgdiplus) с русскими подписями, штук 8–12. Установщик кладёт их в `Assets\Images\Memes` как `ru-*.png` (в корень только картинки). Колода без повторов подхватит их сама. Можно добавить в пульт кнопку «Открыть папку мемов», чтобы пользователь докидывал свои картинки.
3. Установщик может долго искать по дискам (PowerShell `Get-ChildItem` медленный). Стоит искать через `cmd /c dir /s /b X:\GooseDesktop.exe`, добавить общий рабочий стол и папки OneDrive. Если папка гуся есть, а `GooseDesktop.exe` пропал, сказать, что его, скорее всего, удалил Защитник Windows, и показать, как вернуть.
4. Идеи, которые предлагались, но пользователь их не выбирал (без его просьбы не делать): режим созвона, клин гусей, ИИ-гусь, чтение записок вслух, гардероб, реакции, анти-прокрастинатор, заставка.

## Правила репозитория

- Коммиты оканчиваются строками атрибуции, которые задаёт твоя среда. Названия моделей в коммиты и файлы не писать.
- Пуш: `git push -u origin claude/great-maxwell-epaumj`. При сетевой ошибке повтори до 4 раз с паузами 2, 4, 8, 16 с.
- Пиши код в стиле окружающего кода. Перед пушем прогоняй тесты. После изменений собирай zip (как в предыдущих версиях: Python `zipfile`, чтобы русские имена файлов были в UTF-8), отправляй его пользователю и коротко по-русски объясняй, что нажать.
