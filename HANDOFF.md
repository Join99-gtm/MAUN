# Промт для продолжения работы над GooseDeluxe

Скопируй всё ниже в новый чат (Claude Code или Claude с доступом к репозиторию) целиком.

---

Ты продолжаешь работу над **GooseDeluxe**: это мод для Desktop Goose 0.31 (гусь, который бегает по рабочему столу Windows). Весь код лежит в репозитории GitHub **Join99-gtm/MAUN**, в ветке **`claude/great-maxwell-epaumj`**. Работу продолжай в этой ветке. Pull request создавай, только если тебя попросят. Всё прочитай, прежде чем что-то менять. Последняя версия мода — **0.8.0** (говорящий гусь), всё запушено.

## Как общаться с пользователем

- Пиши **только по-русски**, и всё видимое пользователю в моде тоже должно быть на русском. Он прямо просил: «делай всё на русском».
- Пользователь не программист. Его раздражают длинные многошаговые инструкции («сделай всё сам»). Давай 1–3 шага, а лучше делай так, чтобы шагов не было совсем. Готовую сборку отправляй **одним zip-архивом с установщиком** и отдельной карточкой файла (`SendUserFile`, `display: attach`). Однажды он не заметил zip среди картинок и спросил «Где zip?».
- Он присылает скриншоты. Смотри на них внимательно: скриншоты много раз давали разгадку (например, английская записка «Not-epad» показала, что мод не загружен).
- Облачные кредиты ограничены, **прошлый чат кончился на середине задачи** (см. «Незаконченная задача»). Сохраняй результат (коммит и пуш) после каждого законченного куска и держи этот файл (`HANDOFF.md`) свежим: когда «токены заканчиваются», пользователь просит его обновить. Отправляй его как «Промт-для-продолжения.md».
- Чужое творчество в мод не вшивать: трек PHONKMANA пользователь кладёт сам в папку «Фонк»; реплики и голос гуся из Atomic Heart не брать — делаем **свой** голос в похожем стиле; чужие мемы не брать, рисовать свои.

## Как устроен мод (главное)

- Мод — `GooseDeluxe/` (C#, .NET Framework 4.5.2, WinForms, GDI+), собирается в `GooseDeluxe.dll`. Ставится в `<гусь>\Assets\Mods\GooseDeluxe\` вместе с `GooseDeluxe.ini`. В `config.ini` гуся нужен `EnableMods=True`. При каждом запуске гусь спрашивает «Mod Enabler Warning» (окно автора гуся, по-английски), ответить нужно «Да».
- Как гусь грузит моды (`ModSupport.LoadMods`): `Assembly.UnsafeLoadFrom` для каждой .dll в каждой папке `Assets/Mods/*`. Ищет типы `IMod` и `GooseTaskInfo` (поэтому свои задачи из `Tasks/` гусь находит сам). Если `GetTypes` падает, показывает окно «Couldn't Load Mod». Если `Init()` мода бросит исключение, упадёт весь гусь.
- `ModEntryPoint` → `Controller.Init`: пишет лог и `GooseDeluxe.status`, ставит русские записки (`RussianPack`) и в фоне русские мемы (`MemeTranslator.Apply`). Остальное подключается на первом `PreTick` (`Controller.Hook`): своё окно-оверлей с попиксельной прозрачностью (`OverlayWindow`, `UpdateLayeredWindow`), фиксированный шаг 120 Гц (`Fixes/FixedTimestep`), честная колода проделок (`Fixes/DeckFixer`), заморозка движка и подмена цикла простоя гуся (`Fixes/Engine`), полноэкранные игры (`Fixes/FullscreenDetector`), трей (`UI/Tray`), горячие клавиши Ctrl+Alt+G/H/P/M (`RegisterHotKey` плюс опрос `Fixes/HotkeyPoller`), гости и гусиная почта через ntfy.sh (`Net/`, `Tasks/`, `Guests.cs`), времена года (`Seasons/`), звук дрифта (`UI/DriftAudio`).
- `GooseDeluxe.status` — одна строка `started|hooked|failed | время UTC | версия | подробности`. По ней установщик понимает, что мод работает.
- Своё окно ловит клики только там, где курсор над гусем или над кучей листьев (снимается `WS_EX_TRANSPARENT`). Правый клик по гусю открывает меню, левый — гудок (`Controller.OnLeftClick`), клик по куче «пинает» её (`AutumnControl.KickAt` → `LeafPile.Kick` осеннего мода). Над каждой кучей в нашем окне лежит заливка с альфой 1/255, иначе окно пропускает клик; есть запасной опрос левой кнопки через `GetAsyncKeyState`.
- Цикл гуся `Program.HandleApplicationIdle` каждые ~8 мс делал `mainForm.TopMost = true`, и наши окна теряли фокус (пульт не кликался). `Fixes/Engine.OnIdle` заменяет его таким же циклом с `SetWindowPos(... SWP_NOACTIVATE)`.
- Мемы и записки без повторов (`UI/GooseForms` + `NoRepeatDeck`): гусь создаёт окно мема/блокнота в начале задачи, а показывает позже из другого потока; мы до показа подменяем картинку или текст и переименовываем «Goose "Not-epad"» в «Гусиный «Блокнот»».
- Мемы по-русски (`MemeTranslator`): для Meme1, 2, 3, 5, 6, 7 английский текст стирается заливкой из окружения и вписывается русский. Русские копии лежат в `Assets\Images\Memes`, оригиналы в `Memes\en`. Гусь берёт из корня папки **любой файл**, не-картинки туда класть нельзя.
- Звуки: топот лап гусь играет через `SoundPlayer` (один звук за раз), гудки и музыку — через MCI (`mciSendString … type MPEGVideo`). Наши звуки тоже идут через MCI (`UI/DriftAudio`), чтобы не обрывать топот: `open … type mpegvideo alias …`, если не вышло — обычный `open`; громкость `setaudio … volume to 0..1000`. WAV синтезируются кодом (`DriftSynth`: генераторы, биквад-фильтры, реверберация Шрёдера, `Wav()`/`Ensure()`) и сохраняются рядом с модом.
- Гусь: скорости Walk 80 / Run 200 / Charge 400; курсор — `Input.mouseX/mouseY`; задачи — `GooseTaskInfo` (`GetNewTaskData`/`RunTask`), пример короткой своей задачи — `Tasks/ChaseCursorTask.cs`. Помощники в `Deluxe.cs` (`SetTask`, `IsCurrentTask`, `Done`, `SetSpeed`, `HonkBy`, `BeakOf`). Анимация — `GooseAnimator` (поза `GoosePose`: `beakOpen` 0..1, `head2EndPoint` — кончик клюва, `neckHeadPoint`), рисование — `GooseRenderer`, частицы — `Particles`, кадр собирает `Controller.DrawFrame`.
- Пульт (`UI/ControlPanel`), три вкладки: «Пульт», «Настройки», «Проверка» (самопроверка и «Скопировать отчёт»). Меню трея — `UI/Tray`, интерфейс действий — `UI/IGooseControls` (его же реализует подделка в `tools/UiPreview` со списком ожидаемых вызовов кнопок). Все настройки — `DeluxeConfig` / `GooseDeluxe.ini`; новые ключи сами дописываются в старый ini (`AddedIn` даёт версию для комментария).
- Установщик: `installer/install.ps1` (UTF-8 **с BOM**) и `installer/Установить GooseDeluxe.bat` (только ASCII и **CRLF**). Коды выхода: 0 — успех, 2 — мод не отозвался, 3 — ошибка, уже показанная. Ставит мод во **все** копии гуся, перезапускает гуся, до 150 с ждёт статус, объясняет неудачу по-русски и копирует отчёт в буфер (`install-report.txt`).

## 0.8 — говорящий гусь (сделано, ждём отзыва пользователя)

Пользователь прислал 30 фраз для инженера ПТО («надо добавить эти фразы гусю и так чтобы он их озвучивал по-гусиному»), потом: «постарайся сделать голос гуся как в атомик харт» (в Atomic Heart, DLC «Инстинкт истребления», есть говорящий гусь-матерщинник: низкий наглый мужской голос; записи из игры не берём, голос актёра не копируем), «добавь кнопку в менюшке, чтобы при нажатии он рандомную выдавал» и «он должен и сам периодически ходить их говорить». Всё это есть в 0.8:

- Фразы — `GooseDeluxe/Фразы.txt` (вшит в DLL ресурсом `GooseDeluxe.Phrases.txt`; при первом запуске пишется рядом с модом в UTF-8 с BOM и больше не перезаписывается). `Speech/PhraseBook.cs` перечитывает файл при изменении, раздаёт по кругу без повторов (`NoRepeatDeck`, есть `Peek` — следующая готовится заранее).
- Облачко — `Speech/SpeechBubble.cs` (раскладка строк один раз, текст печатается по словам в такт, хвост к голове, у верхнего края — под гусём). Клюв — `GooseAnimator.TalkOpen` по огибающей громкости, `Talking` глушит зевки.
- Голос — `Speech/Speaker.cs` (звук готовится в фоне на ThreadPool, играет через MCI `UI/SpeechAudio.cs`, alias `gdvoice`), `Controller.BuildUtterance`:
  - `PhraseVoice=Atomic` (по умолчанию): `UI/WindowsVoice.cs` — System.Speech, русский голос (предпочитает мужской; женскому ставит Rate 3 и опускает ×0.72, мужскому Rate 1 и ×0.88), затем `Speech/VoiceFx.Goose` (кубическое пересэмплирование вниз, EQ: срез 85 Гц, +2.5 дБ 190 Гц, +5.5 дБ 1150 Гц «нос», +2.5 дБ 2800 Гц, ФНЧ 5,5 кГц, перегруз tanh, немного реверберации). Текст для синтезатора — `SpeechText.ForSynthesizer` (ПТО → «пэ-тэ-о», КС-2 → «ка-эс-2», «Ни-ху-я» → «Ни ху я», растянутые гласные короче). Проверено на RHVoice под Linux: Ирина 190 Гц → 137 Гц. **На настоящей Windows голос не проверен** — спроси пользователя, как звучит.
  - Если русского голоса нет или System.Speech не грузится (под Wine так и есть) — `Speech/GooseVoice.cs`: каждый слог — короткий гудок (~610–700 Гц, спектр как у Honk1-4.mp3, форманты гласных, шум согласных, «!»/«?»/«…» меняют интонацию). `Goose` — выбрать его сразу, `Off` — только облачко.
  - WAV кладутся в `%TEMP%\GooseDeluxe\<версия>\`.
- Когда говорит: «Сказать фразу» (жирным в меню по правому клику/у часов и в пульте), клик по гусю (если он молчит), сам — `RandomPhrases`, в среднем раз в `RandomPhraseMinutes` = 5 минут (`Tasks/SayTask.cs`: бежит к курсору до 4 с, встаёт сбоку, стоит, пока говорит), в 50 % погонь за курсором кричит фразу, с телефона «фраза» или «скажи <текст>» (`FriendProtocol.ParseSay`), «Сказать другу фразу» (его гусь говорит фразу из своего списка). «Фразы гуся (дописать свои)…» открывает файл в Блокноте. Строка «Фразы» во вкладке «Проверка» показывает число фраз, голос (или почему гусиный) и когда он подойдёт сам.
- Проверено: 222 автотеста, пульт (UiPreview), настоящий гусь под Wine — клик по гусю и сам подход к курсору с облачком (голос под Wine гусиный).
- Возможные следующие шаги по отзыву: другой тембр (сдвиг 0.65–0.8, больше/меньше хрипа), мужской голос (Windows «Pavel» есть только в OneCore — нужен WinRT `Windows.Media.SpeechSynthesis`; или бесплатный RHVoice «Aleksandr» для Windows с SAPI5), чаще/реже фразы, фразы в записках гуся.

## Сборка и проверка (Linux, облачная сессия)

```
export DOTNET_ROLL_FORWARD=Major PATH="$PATH:/root/.dotnet/tools"
dotnet build GooseDeluxe -c Release
dotnet run --project tools/Tests -c Release -- tools/mock_ntfy.py "<папка гуся>"      # 222 проверки, должно быть ALL PASSED
(cd tools/UiPreview && dotnet build -c Release && xvfb-run -a mono bin/Release/net452/UiPreview.exe clicks)   # CLICK TEST PASSED
dotnet run --project tools/Tests -c Release -- --write-default-ini GooseDeluxe/GooseDeluxe.ini
SP=/tmp/goose-work bash tools/installer-tests/scenarios.sh          # установщик, pwsh 7, -NoLaunch
SP=/tmp/goose-work bash tools/installer-tests/launch-scenarios.sh   # установщик с «гусём-подделкой»
```

- Для тестов нужен сам гусь. Попроси у пользователя `Desktop_Goose_v0.31.rar` и распакуй `bsdtar -xf` в `$SP/goose/`, чтобы получилось `$SP/goose/Desktop Goose v0.31/DesktopGoose v0.31/`. Из него же взят `lib/GooseModdingAPI.dll`.
- Инструменты:
  - .NET SDK (+ `DOTNET_ROLL_FORWARD=Major`), mono, xvfb, ImageMagick;
  - для установщика — pwsh (`dotnet tool install -g powershell`);
  - для анализа снимков и звука — python3, pillow, numpy и `pip install miniaudio` (декодирует MP3 гуся; ffmpeg и scipy в контейнере нет).
- **Настоящий гусь под Wine** (так проверялись 0.5–0.7):
  1. `dpkg --add-architecture i386`, затем `apt-get install wine wine32:i386 xdotool xcompmgr`. Если мешает `libgd3:i386`, сначала поставь его отдельно.
  2. Wine Mono 8.1.0 скачай с GitHub (`wine-mono-8.1.0-x86.tar.xz`, dl.winehq.org закрыт прокси) и распакуй в `/usr/share/wine/mono/`.
  3. `locale-gen ru_RU.UTF-8`.
  4. `WINEARCH=win32 WINEPREFIX=$SP/wp wineboot -i`.
  5. Положи гуся в `$SP/wp/drive_c/users/root/Desktop/Гусь` и поставь `EnableMods=True`.
  6. Запуск: `tools/wine/wine_start.sh`. Он поднимает Xvfb :77 с xcompmgr (без композитора альфа 1/255 рисуется чёрным), жмёт «Да» и ждёт статус. Помощники: `leaves.py`, `findgoose.py`, `textbox.py`.
  7. Команды гусю можно слать через `tools/mock_ntfy.py`: `NtfyServer=http://127.0.0.1:порт` в ini, POST «мем»/«записка» в топик `goosedeluxe-<код в нижнем регистре без дефисов>`.
- Ограничения Wine:
  - Ctrl+Alt+M не срабатывает;
  - PowerShell 7 для Windows под Wine 9 падает;
  - MCI `type mpegvideo` даёт ошибку 277, работает запасной обычный `open`.
- Не убивай процессы через `pkill -f` с шаблоном, совпадающим с твоей же командой: это убьёт твою оболочку. Используй `pgrep -x` или `setsid`.
- Пакет собирается через Python `zipfile`, чтобы русские имена были в UTF-8. Состав: `install.ps1`, `Установить GooseDeluxe.bat`, `ЧИТАЙ МЕНЯ.txt` (сверху раздел «ЧТО НОВОГО В …»), `Assets/Mods/GooseDeluxe/GooseDeluxe.dll` и `GooseDeluxe.ini`. Прошлые сборки лежали во временной папке и в новом чате их не будет: собери по этому списку, «ЧИТАЙ МЕНЯ» напиши заново.

## Правила репозитория

- Коммиты оканчиваются строками атрибуции, которые задаёт твоя среда. Названия моделей в коммиты и файлы не писать.
- Пуш: `git push -u origin claude/great-maxwell-epaumj`. При сетевой ошибке повтори до 4 раз с паузами 2, 4, 8, 16 с.
- Пиши код в стиле окружающего кода: комментарии в коде по-английски, всё для пользователя — по-русски. Перед пушем прогоняй тесты. После изменений собирай zip, отправляй его пользователю и коротко по-русски объясняй, что нажать.
