# files_middleclick — клик колёсиком по файлу в Nextcloud

## Проблема

В приложении «Файлы» имя файла сделано кнопкой, а не ссылкой, а список файлов
прокручивается. Chrome на Windows воспринимает нажатие колёсика на таком
элементе как включение автопрокрутки и не сообщает странице о клике средней
кнопкой (событие `auxclick` не приходит). Поэтому обработчик Nextcloud
`FileEntryMixin.execDefaultAction`, который открывает файл в новой вкладке,
не вызывается. Права на файлы, всплывающие окна и ONLYOFFICE ни при чём.

## Что делает приложение

Подключает к «Файлам» и к страницам общих ссылок один скрипт `js/main.js`
(20 строк). При нажатии **средней** кнопкой на имени или иконке файла он
отменяет действие браузера по умолчанию (автопрокрутку), и клик доходит до
Nextcloud как обычно. Левая и правая кнопки, перетаскивание, выделение,
переименование, контекстное меню не затрагиваются. Файлы самого Nextcloud
не изменяются, поэтому обновления Nextcloud приложение переживает.

Подходит для Nextcloud 31–34 (проверено на 33.0.0).

## Установка (делает админ)

```bash
# 1. Распаковать в каталог apps Nextcloud (например /var/www/nextcloud/apps)
tar -xzf files_middleclick-1.0.0.tar.gz -C /var/www/nextcloud/apps/

# 2. Выставить владельца, как у остальных приложений (www-data на Debian/Ubuntu)
chown -R www-data:www-data /var/www/nextcloud/apps/files_middleclick

# 3. Включить
sudo -u www-data php /var/www/nextcloud/occ app:enable files_middleclick
```

Если Nextcloud в Docker: скопировать каталог в контейнер
(`docker cp files_middleclick <контейнер>:/var/www/html/apps/`) и выполнить
`docker exec -u www-data <контейнер> php occ app:enable files_middleclick`.

Перезапуск сервера не нужен. Пользователям достаточно обновить страницу (F5).

## Проверка

Открыть «Файлы» и нажать колёсиком по имени файла: файл должен открыться в
новой вкладке. В консоли браузера (F12 → Network) должен загружаться
`apps/files_middleclick/js/main.js`.

## Откат

```bash
sudo -u www-data php occ app:disable files_middleclick
# при желании удалить полностью:
sudo -u www-data php occ app:remove files_middleclick
```

После отключения всё возвращается к исходному поведению.

## Как проверялось

На локальной установке Nextcloud 33.0.0 (SQLite, PHP 8.4) в Chromium через
Playwright, с включённым и выключенным приложением: загрузка скрипта,
клик колёсиком, Ctrl+клик, левый клик по файлу и папке, правый клик
(контекстное меню), перетаскивание файла в папку, выделение чекбоксом,
страница общей ссылки, отсутствие ошибок JS и записей в `nextcloud.log`.
Все 17 проверок прошли.
