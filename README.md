# GooseDeluxe — мод для Desktop Goose 0.31

Графика, анимации, починка багов и «гусиная почта» для гуся, не трогая сам `GooseDesktop.exe`.
Мод гасит родной рендер (окно гуся с цветовым ключом не умеет полупрозрачность) и рисует гуся
в собственном окне с честной per-pixel alpha (`UpdateLayeredWindow`).

## Что добавляет

Графика и анимации (0.1):

- сглаженный гусь без «лесенки», мягкая тень, ноги;
- перевалка при ходьбе, плавные развороты, squash & stretch при разгоне/торможении;
- голова поворачивается за курсором, глаза следят, моргание;
- idle-анимации: зевок с потягиванием, встряхивание головы (перья летят), чистка перьев;
- крылья раскрываются при разбеге и хлопают при гудке, клюв открывается, всплывает «ГА-ГА-ГА!»;
- пыль из-под лап на бегу, «линии борьбы» у клюва, пока гусь держит курсор;
- шляпы: цилиндр, колпак, шапка Деда Мороза; масштаб гуся.

Починка оригинала и удобство (0.2):

- **правильная скорость**: гусь считает физику шагом 1/120 с, а крутится на ~64 FPS, поэтому в оригинале
  ходит почти вдвое медленнее задуманного; мод прогоняет его «мозг» ровно 120 раз в секунду;
- **честный рандом**: `SamEngine.Deck` перемешивает алгоритмом Саттоло, и три проделки гуся идут всего
  в 2 порядках из 6 (после записки всегда грязь); мод перетасовывает колоду заново после каждого круга;
- **не мешает в играх и кино**: пока на основном экране полноэкранная игра, видео или презентация, гусь
  полностью засыпает — не рисуется, не дёргает TopMost и не отпускает курсор из игры (оригинал каждый
  кадр вызывает `ClipCursor(NULL)`);
- **значок в трее** с меню и горячие клавиши: Ctrl+Alt+G — позвать гуся, Ctrl+Alt+H — гудок,
  Ctrl+Alt+P — пауза (гусь спит, «z» над головой); «без звука» и «можно красть курсор» — прямо из меню;
- **по-русски**: «ГА-ГА-ГА!» вместо HONK и 15 русских записок в блокноте гуся (английские
  убираются в `*.txt.en` и возвращаются, если выключить `RussianNotes`).

Гусь к другу (0.2):

- у каждого гуся свой код `GUS-XXXX-XXXX-XXXX`; его знает только тот, кому ты его дал;
- «Отправить записку / картинку»: твой гусь хватает её в клюв и убегает за край экрана, а у друга из-за
  края выходит **твой гусь** — в твоих цветах и шляпе, с твоим именем над головой — затаскивает окно
  с запиской, гудит и уходит; у записки есть кнопка «Ответить гусём»;
- пранки: «Сбегать в гости», «Принести другу мем», «Наследить у друга», «Украсть курсор у друга» —
  всё это делает твой гусь у друга на экране;
- пульт с телефона: ссылка `https://ntfy.sh/goosedeluxe-…` открывается в браузере, туда можно писать
  `га`, `мем`, `записка`, `сюда`, `грязь`, `кража` или любой текст — твой гусь принесёт его запиской;
- почта идёт через бесплатный сервер [ntfy](https://ntfy.sh) (без регистрации); сервер можно заменить
  своим (`NtfyServer`). Картинки качаются только с этого сервера, до 8 МБ, только PNG/JPG/GIF/BMP;
  кража курсора другом — не чаще раза в минуту и выключается (`FriendCanStealMouse`).

Всё выключается по отдельности в `GooseDeluxe.ini`; новые ключи сами дописываются в старый файл.

## Установка

Самый простой путь — установщик из архива `GooseDeluxe-vX.zip`: распаковать zip, запустить
«Установить GooseDeluxe.bat». Он найдёт гуся на диске (или распакует `Desktop_Goose_v0.31.rar`
из «Загрузок», если есть WinRAR/7-Zip), перенесёт его в папку «Гусь» на рабочем столе, скопирует
мод, включит `EnableMods` и сделает ярлык. Скрипт — `installer/install.ps1`, работает на
Windows PowerShell 5.1 без прав администратора, лог пишет в `install-log.txt` рядом с собой.

Вручную:

1. Скопировать `GooseDeluxe.dll` и `GooseDeluxe.ini` в `Assets/Mods/GooseDeluxe/` рядом с `GooseDesktop.exe`
   (папку создать; в ней не должно быть `GooseModdingAPI.dll`).
2. В `config.ini` поставить `EnableMods=True`.
3. Запустить гуся, в диалоге про моды нажать «Yes».

Если что-то пошло не так, мод сам отключается и возвращает родной рендер, а причина
пишется в `Assets/Mods/GooseDeluxe/GooseDeluxe.log`.

## Как это устроено

- `GooseDeluxe/Controller.cs` — всё подключение к гусю: рендер, починки, пауза, трей, почта, гости.
- `Fixes/` — `FixedTimestep` (обёртка над `goose.tick`), `DeckFixer`, `Engine` (заморозка через
  отписку `Application.Idle` и `canvas.Paint` гуся), `FullscreenDetector`, `GooseSettings`.
- `Net/` — клиент ntfy (подписка потоком с `since` при переподключении), протокол, коды, почтовый ящик.
- `Tasks/` — задачи гуся (`GooseTaskInfo`): «сюда», «унести», «принести», визит и уход гостя.
- `Guests.cs` — гость: второй `GooseEntity`, которого двигают те же `TickGoose`/`UpdateRig` гуся.

## Сборка и проверка

```
dotnet build GooseDeluxe -c Release
dotnet run --project tools/Tests -c Release -- tools/mock_ntfy.py
dotnet run --project tools/Preview -c Release -- preview-out
```

- `GooseDeluxe/bin/Release/net452/GooseDeluxe.dll` — сам мод; `lib/GooseModdingAPI.dll` — официальный
  API из папки `FOR MOD-MAKERS` дистрибутива гуся.
- `tools/Tests` компилирует всё, что не зависит от WinForms, под .NET 8 с флагом `HEADLESS`: колода,
  шаг времени, коды, протокол, конфиг, русские записки, задачи в симуляции гусиного мира, гости,
  и сквозной обмен двух «гусей» через `tools/mock_ntfy.py` (имитация ntfy: публикация, поток,
  вложения, обрыв связи).
- `tools/Preview` рисует набор состояний гуся в PNG через libgdiplus; `preview-out/contact-sheet.png` —
  все сцены на одном листе.
