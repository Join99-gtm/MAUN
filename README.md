# MAUN — что где лежит

Всё разложено по трём папкам: для чего вещь и кому она нужна.

```
MAUN/
├── README.md                       ← этот файл
├── docs/                           ДОКУМЕНТЫ
│   └── сотрудникам/                    памятки для всех сотрудников
│       └── памятка-сертификат.md           как установить сертификат, чтобы Word/Excel открывались в Nextcloud
├── nextcloud/                      ДОРАБОТКИ NEXTCLOUD (для админа)
│   ├── files_middleclick/              приложение: клик колёсиком по файлу открывает его в новой вкладке
│   │   └── README.md                       что это, как установить, проверить и откатить
│   ├── release/                        готовые архивы для установки на сервер
│   │   └── files_middleclick-1.0.0.tar.gz
│   └── tests/                          автопроверки (на сервер не ставятся)
│       └── e2e-middleclick.js
└── server/                         СЕРВЕР (для админа)
    └── health.sh                       проверка состояния сервера, только чтение
```

## Кому что

| Кто | Куда смотреть |
| --- | --- |
| Сотрудник | `docs/сотрудникам/` — там всё, что нужно сделать на своём компьютере |
| Админ Nextcloud | `nextcloud/` — начать с `files_middleclick/README.md`, ставить архив из `release/` |
| Админ сервера | `server/health.sh` — запуск: `bash health.sh`, ничего не меняет |

## Куда класть новое

- Памятка или инструкция для людей → `docs/сотрудникам/`
- Документ для админов → `docs/` (при необходимости завести `docs/админам/`)
- Новое приложение или правка Nextcloud → `nextcloud/<имя_приложения>/`, архив → `nextcloud/release/`, тесты → `nextcloud/tests/`
- Скрипт для сервера → `server/`
