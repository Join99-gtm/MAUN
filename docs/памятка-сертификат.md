# Как включить редактирование Word и Excel в Nextcloud

Чтобы документы открывались в браузере без предупреждений, нужно один раз
установить на компьютер сертификат нашей офисной сети. Это займёт 2 минуты
и делается только на компьютерах, с которых вы заходите в Nextcloud.

К письму приложен файл **ca.crt**. Это не секретный файл, его можно
свободно передавать.

## Windows, способ 1 (мышкой)

1. Сохраните файл `ca.crt` на компьютер (например, в «Загрузки»).
2. Дважды щёлкните по нему. Откроется окно «Сертификат».
3. Нажмите **«Установить сертификат…»**.
4. Выберите **«Локальный компьютер»** → «Далее». Windows может спросить
   разрешение, нажмите «Да».
5. Выберите **«Поместить все сертификаты в следующее хранилище»** → «Обзор».
6. В списке выберите **«Доверенные корневые центры сертификации»** → «ОК» → «Далее» → «Готово».
7. Появится вопрос «Установить этот сертификат?», нажмите **«Да»**.
8. **Полностью закройте браузер** (все окна) и откройте заново.

## Windows, способ 2 (одной командой)

1. Сохраните `ca.crt` в папку «Загрузки».
2. Откройте PowerShell **от имени администратора**: Пуск → наберите
   `PowerShell` → правой кнопкой → «Запуск от имени администратора».
3. Вставьте и нажмите Enter:
   ```powershell
   Import-Certificate -FilePath "$env:USERPROFILE\Downloads\ca.crt" -CertStoreLocation Cert:\LocalMachine\Root
   ```
4. Полностью закройте браузер и откройте заново.

## macOS

1. Дважды щёлкните по `ca.crt`, откроется «Связка ключей».
2. Найдите сертификат **Office Root CA**, дважды щёлкните по нему.
3. Раскройте раздел «Доверие» и в пункте «При использовании этого
   сертификата» выберите **«Всегда доверять»**. Закройте окно, введите пароль.
4. Перезапустите браузер.

## Проверка

Откройте в браузере <https://10.10.106.144:8443/healthcheck>.
Должно быть слово `true` и замок в адресной строке, без предупреждения
«Подключение не защищено».

Затем откройте любой файл Word или Excel в Nextcloud: он откроется прямо
в браузере.

## Если не сработало

- Убедитесь, что браузер был закрыт полностью, а не просто вкладка.
- Проверьте, что при установке выбрано «Локальный компьютер», а не
  «Текущий пользователь», и хранилище «Доверенные корневые центры сертификации».
- Если всё равно не работает, напишите администратору, укажите, какой
  браузер и что именно показывает страница.
